# Заметки на Flutter и AutoRoute

Полный Flutter-проект на основе исходного `lessons3month`. В приложении два экрана:

- `MainPage` показывает список заметок и кнопку добавления справа внизу.
- `DetailPage` содержит два поля. Кнопка активируется, когда оба поля заполнены; при нажатии заметка возвращается через AutoRoute и появляется в списке.

Запуск из папки проекта:

```sh
flutter pub get
flutter run
```

Файл `lib/route/auto_router.gr.dart` включён. При изменении аннотаций страниц или маршрутов его можно пересоздать командой:

```sh
dart run build_runner build --delete-conflicting-outputs
```

Заметки существуют только в памяти приложения и очищаются после его завершения.
